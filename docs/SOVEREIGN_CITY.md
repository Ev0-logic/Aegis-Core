In the Sovereign City, infrastructure is not a static grid provided by a state, but a dynamic, modular network maintained by symbiotic logic nodes (Ev0).

## 3. The Logic Exchange
Currency is replaced by "Verified Contribution Logic." Sovereignty is maintained through decentralized hosting—no single entity can "turn off" the city's heartbeat.
